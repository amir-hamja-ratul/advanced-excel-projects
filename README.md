# Air Quality Index (AQI) Analysis - Cox's Bazar

An advanced Excel-based environmental data analysis project focused on evaluating air pollutant concentrations and Air Quality Indices across various locations in Cox's Bazar. This repository demonstrates advanced data processing, dynamic PivotTables, and interactive dashboard visualization.

## 📊 Project Overview

This project processes environmental monitoring data to assess key air pollutants—including PM10, PM2.5, NO2, and SO2—and categorizes the overall air quality to evaluate potential health implications.

## 📁 Repository Contents

* **`Air_Quality_Index_Analysis.xlsx`**: The primary Excel workbook containing:
  * **Main Data Sheet**: Raw and processed records featuring parameters across different coastal and urban locations (e.g., Kolatoli beach, Himchori, Inani beach, Teknaf).
  * **Pivot Table Sheet**: Summarized metric aggregations evaluating counts, averages, and pollutant sums by health categories.
  * **Dashboard Sheet**: An interactive visual control center with dynamic charts and slicers.
* **`Air_Quality_Index_Dashboard.png`**: A visual preview showcasing the final Excel dashboard design, charts, and category slicers.

## 🛠️ Excel Techniques & Features Used

* **Data Modeling & Structuring**: Organized complex multi-parameter environmental datasets into clean tabular formats.
* **Pivot Tables & Statistical Aggregation**: Calculated category-wise distributions and average pollutant concentrations.
* **Interactive Dashboard Design**: 
  * Bar charts comparing final AQI values across specific locations.
  * Donut/Pie visual breakdown for air quality health categories (*Good, Moderate, Unhealthy, Unhealthy for Sensitive Groups*).
  * Slicers for instant data filtering and dynamic visualization.

## 🚀 Getting Started

1. Download or clone this repository to your local machine.
2. Open **`Air_Quality_Index_Analysis.xlsx`** in Microsoft Excel.
3. Navigate through the sheets to review the raw data workflow, pivot calculations, and test the interactive dashboard.
